# digup.run — Digup Run product site

Product download and install guides for **[Digup Run](https://digup.run)** — local multimodal semantic file search.

- App binaries: [ylwl1997/digup-run-app Releases](https://github.com/ylwl1997/digup-run-app/releases) (this site hosts **no** binaries)
- Based on [ARahim3/DigUp](https://github.com/ARahim3/DigUp) (MIT). **Not** an official DigUp / ARahim3 product.

## Stack

- [Astro](https://astro.build) SSG → Cloudflare Pages (`npm run build` → `dist/`)

## Develop

```bash
npm install
npm run dev
```
